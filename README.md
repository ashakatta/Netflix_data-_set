📊 Netflix Dataset Analysis
📌 Overview
This project focuses on exploratory data analysis (EDA) of the Netflix dataset using Python. The notebook analyzes Netflix content to uncover insights about movies and TV shows, release trends, country-wise distribution, and content growth over the years.

The objective is to practice data cleaning, transformation, and analysis using real-world data.

🗂️ Key Features
Load and explore the Netflix dataset

Display initial insights (first rows, shape, columns, data types)

Handle missing values effectively

Convert date columns to proper datetime format

Identify the most common content categories

Analyze:

Content distribution by country (Top 5 countries)

Movies vs TV Shows comparison

Average release year trends

Year-wise content added to Netflix

Use groupby() and aggregation functions for insights

🛠️ Technologies Used
Python

Pandas

NumPy

Jupyter Notebook

📁 Dataset
Netflix Movies and TV Shows dataset

Contains information such as:

Title

Type (Movie / TV Show)

Country

Release Year

Date Added

Genre

▶️ How to Run
Clone the repository

Open Netflix.ipynb in Jupyter Notebook

Run the cells sequentially to view analysis and results

Practical experience with real-world datasets
